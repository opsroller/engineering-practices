# Provenance

Everything that ships must be something the project may ship.

## Always

- Create code and assets from scratch, or use material under a license
  the project profile allows (record source and license).
- Prefer generated assets: commit the script so anyone can regenerate.
- Log every new asset file or folder in the project's provenance log:
  path, how it was made (script, tool, or source URL), license.

## When recreating an existing work

- Ideas, rules and mechanics may be reimplemented; expression may not.
  Never copy, extract, trace, resample or closely imitate the original's
  code, art, audio, text or level files.
- Describe the original only in your own words, as observed behaviour.
- Use the original's name only where the project profile allows it
  (typically credits), never as your title, logo or branding.

If unsure whether something crosses the line, leave it out and say so in
the PR.
